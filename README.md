# -RetroPie-handheld-console-guide-for-Raspberry-Pi-Zero-W-
End-to-end DIY RetroPie handheld console guide for Raspberry Pi Zero W featuring a 2.8" ILI9341 SPI display (32 MHz), MAX98357A I2S digital audio with ALSA softvol, and 10 tactile buttons mapped via Linux kernel Device Tree Overlays (gpio-keys) with zero CPU overhead.
